# Enviar los ajustes al Mustang LT25 — Plan de Implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que la app escriba `gain`, `treb` y `bass` del nodo `amp` del preset activo del amplificador, por WebHID, confirmando cada escritura con el ACK del equipo.

**Architecture:** El protocolo puro (protobuf, framing, reensamblado) vive en `public/fender-protocolo.js`, separado del ciclo de vida WebHID en `public/ampli-usb.js`. La separación existe para que `test/` pueda importar el protocolo directo desde disco y cubrirlo con la suite, aunque el front no tenga tests. La conversión de escala ocurre en el servidor.

**Tech Stack:** Node 25, WebHID (Chrome/Edge), cero dependencias. Vanilla JS sin build.

**Spec:** `docs/superpowers/specs/2026-09-05-ampli-usb-design.md`

## Global Constraints

- **Node >= 24. Cero dependencias npm.** Ni en el proyecto ni para esta función. WebHID es del navegador; `node:test` es built-in.
- **ESM**: `import`, nunca `require`.
- **Tests con `node:test`** y `node:assert/strict`, corridos con `npm test`.
- **Ningún test toca la red ni el hardware.** El protocolo se prueba con bytes capturados; el ciclo WebHID se verifica a mano.
- **Idioma**: texto de interfaz, mensajes y comentarios en español; API pública, nombres de archivo y de parámetro del amplificador (`gain`, `treb`, `bass`, `amp`) en inglés. Variables locales pueden ir en español.
- **`ponerParametro` SIEMPRE espera el ACK.** El amplificador ignora en silencio lo malformado: sin confirmación, no hubo cambio. Nunca declarar éxito sin ACK.
- **No se manda `volume` ni `mid` ni `reverb`.** Decisión de seguridad física y de alcance, documentada en la spec §4.
- **Un commit por tarea**, con la suite pasando.

### Datos del amplificador, verificados contra el equipo real

| dato | valor |
|---|---|
| Vendor / Product ID | `0x1ed8` / `0x0037` |
| Envío | `sendReport(0, Uint8Array(64))` |
| Framing | `[tag, largo, ...carga, relleno]`; tag `0x35` único, `0x33` inicio, `0x34` continuación |
| **Recepción** | `e.data` **SÍ trae el byte nulo inicial**: tag en `d[1]`, largo en `d[2]`, carga desde `d[3]` |
| Handshake | `SYNC_BEGIN` antes de todo; sin él, cero respuestas |
| Heartbeat | cada segundo |

/* ---------------------------------------------------------------------------
   Protocolo del Fender Mustang LT (serie LT), reimplementado desde la
   documentacion de LtAmp y verificado contra el equipo real.

   Este archivo es PURO a proposito: no toca WebHID ni el DOM. Vive en public/
   porque el navegador lo carga como modulo servido, pero `test/` lo importa
   directo desde disco. El front no tiene tests automatizados por decision de
   diseno, y este es justo el codigo donde un desfase de un byte no revienta:
   descarta todo en silencio y se ve igual que "el amplificador no contesta".
   --------------------------------------------------------------------------- */

// --- protobuf, escrito a mano (no hay dependencias en este proyecto) --------
const varint = n => { const b = []; do { let x = n & 0x7f; n >>>= 7; if (n) x |= 0x80; b.push(x) } while (n); return b }

export const campoVarint = (num, val) => [...varint((num << 3) | 0), ...varint(val)]
export const campoBytes = (num, bytes) => [...varint((num << 3) | 2), ...varint(bytes.length), ...bytes]
export const campoTexto = (num, str) => campoBytes(num, [...new TextEncoder().encode(str)])
export const campoFloat = (num, f) => {
  const b = new Uint8Array(4)
  new DataView(b.buffer).setFloat32(0, f, true)
  return [...varint((num << 3) | 5), ...b]
}

/* Todo mensaje va envuelto en un FenderMessageLT: responseType (campo 1) mas el
   submensaje del oneof. El responseType NO es opcional — se probo omitirlo
   contra el equipo y responde con silencio absoluto. */
export const codificarMensaje = (campo, subcampos) =>
  new Uint8Array([...campoVarint(1, 0), ...campoBytes(campo, subcampos)])

// --- framing HID ------------------------------------------------------------
export const TAG_INICIO = 0x33, TAG_CONTINUA = 0x34, TAG_UNICO = 0x35

/* Envio: 64 bytes limpios. WebHID recibe el reportId por separado, asi que
   aqui NO va el byte de reportId. Medido: 63 y 64 funcionan, 65 lo rechaza
   Chrome por exceder el tamano del reporte. */
export function empaquetar(carga) {
  if (carga.length > 61) throw new Error(`la carga no cabe en un paquete: ${carga.length} bytes`)
  const b = new Uint8Array(64)
  b[0] = TAG_UNICO
  b[1] = carga.length
  b.set(carga, 2)
  return b
}

/* Recepcion: `e.data` SI trae el byte nulo inicial del protocolo, asi que el
   tag esta en el byte 1 y no en el 0. Leerlo en el 0 fue un error real durante
   el sondeo y no producia ninguna excepcion: descartaba todas las respuestas.  */
export function crearReensamblador() {
  let partes = []
  return {
    recibir(bytes) {
      const tag = bytes[1], largo = bytes[2]
      const carga = bytes.slice(3, 3 + largo)
      if (tag === TAG_INICIO) { partes = [carga]; return null }
      if (tag === TAG_CONTINUA) { partes.push(carga); return null }
      if (tag !== TAG_UNICO) return null   // tag desconocido: se descarta
      if (!partes.length) return carga
      partes.push(carga)
      const total = new Uint8Array(partes.reduce((a, p) => a + p.length, 0))
      let o = 0
      for (const p of partes) { total.set(p, o); o += p.length }
      partes = []
      return total
    },
  }
}

// --- lectura ----------------------------------------------------------------
export function leerCampos(buf) {
  const salida = []
  let i = 0
  while (i < buf.length) {
    let tag = 0, s = 0
    while (i < buf.length) { const b = buf[i++]; tag |= (b & 0x7f) << s; s += 7; if (!(b & 0x80)) break }
    const num = tag >>> 3, tipo = tag & 7
    if (!num) break
    if (tipo === 0) {
      let v = 0, s2 = 0
      while (i < buf.length) { const b = buf[i++]; v |= (b & 0x7f) << s2; s2 += 7; if (!(b & 0x80)) break }
      salida.push({ num, v })
    } else if (tipo === 2) {
      let l = 0, s2 = 0
      while (i < buf.length) { const b = buf[i++]; l |= (b & 0x7f) << s2; s2 += 7; if (!(b & 0x80)) break }
      salida.push({ num, bytes: buf.slice(i, i + l) }); i += l
    } else if (tipo === 5) {
      salida.push({ num, f: new DataView(buf.buffer, buf.byteOffset + i, 4).getFloat32(0, true) }); i += 4
    } else break
  }
  return salida
}

// --- mensajes concretos -----------------------------------------------------
export const SYNC_BEGIN = codificarMensaje(113, [...campoVarint(1, 0), ...campoVarint(2, 0)])
export const SYNC_END   = codificarMensaje(113, [...campoVarint(1, 1), ...campoVarint(2, 0)])
export const HEARTBEAT  = codificarMensaje(201, campoVarint(1, 1))

export const mensajePonerParametro = (nodo, parametro, valor) =>
  codificarMensaje(34, [...campoTexto(1, nodo), ...campoTexto(2, parametro), ...campoFloat(3, valor)])

const texto = b => new TextDecoder().decode(b)

/* Traduce un mensaje crudo a algo con nombre. Solo reconoce lo que esta
   funcion necesita hoy; el resto cae en 'desconocido' sin lanzar. */
export function interpretar(mensaje) {
  const campos = leerCampos(mensaje)
  const sub = campos.find(c => c.num !== 1)
  if (!sub) return { tipo: 'desconocido' }
  const dentro = sub.bytes ? leerCampos(sub.bytes) : []
  switch (sub.num) {
    case 35: return {
      tipo: 'ackParametro',
      nodo: dentro[0]?.bytes ? texto(dentro[0].bytes) : null,
      parametro: dentro[1]?.bytes ? texto(dentro[1].bytes) : null,
      valor: dentro[2]?.f,
    }
    case 100: return { tipo: 'identificacion', texto: dentro[0]?.bytes ? texto(dentro[0].bytes) : '' }
    case 103: return { tipo: 'firmware', texto: dentro[0]?.bytes ? texto(dentro[0].bytes) : '' }
    case 113: return { tipo: 'sync' }
    default: return { tipo: 'desconocido' }
  }
}

/* Convierte la sugerencia (escala 1-10, pensada para leerse) a lo que el
   amplificador espera de verdad: flotantes continuos de 0 a 1.

   Solo tres parametros, y los que faltan NO son un olvido:

export function paraElAmpli(sugerencia) {
  if (!sugerencia) return null
  const a01 = v => Math.min(1, Math.max(0, (Number(v) - 1) / 9))
  return {
    gain: a01(sugerencia.gain),
    treb: a01(sugerencia.treble),
    bass: a01(sugerencia.bass),
  }
}

### Task 4: El ciclo de vida WebHID

**Files:**
- Create: `public/ampli-usb.js`

**Interfaces:**
- Consumes: todo lo de `public/fender-protocolo.js` (Task 2).
- Produces, desde `public/ampli-usb.js`, un objeto `ampli` con:
  - `soportado()` → `boolean`
  - `conectado()` → `boolean`
  - `conectar()` → `Promise<void>`; lanza con mensaje en español si falla
  - `reconectarSiSePuede()` → `Promise<boolean>`; usa `getDevices()`, sin selector
  - `desconectar()` → `Promise<void>`
  - `ponerParametro(nodo, parametro, valor)` → `Promise<number>` con el valor confirmado; **rechaza si no llega el ACK en 2 s**
  - `alCambiarEstado(fn)` → registra un callback `(conectado: boolean) => void`

Esta tarea **no lleva tests automatizados**: es ciclo de vida de hardware en el navegador. Se verifica en la Task 7.

- [ ] **Step 1: Escribir `public/ampli-usb.js`**

```js
/* ---------------------------------------------------------------------------
   Conexion con el Fender Mustang LT25 por WebHID.

   Solo el ciclo de vida: permiso, apertura, handshake, heartbeat y espera de
   ACK. Todo el formato de mensajes vive en fender-protocolo.js, que si esta
   cubierto por tests.
   --------------------------------------------------------------------------- */
import {
  empaquetar, crearReensamblador, interpretar,
  SYNC_BEGIN, SYNC_END, HEARTBEAT, mensajePonerParametro,
} from './fender-protocolo.js'

const VENDOR = 0x1ed8, PRODUCT = 0x0037
const ESPERA_ACK = 2000        // ms antes de dar por perdida una escritura
const LATIDO = 1000            // el equipo cierra la conexion sin heartbeat

let dispositivo = null
let latido = null
let reensamblador = null
const pendientes = []          // { nodo, parametro, resolver, rechazar, temporizador }
const oyentes = []

const avisar = () => { for (const fn of oyentes) fn(!!dispositivo) }

function alRecibir(e) {
  const mensaje = reensamblador.recibir(new Uint8Array(e.data.buffer))
  if (!mensaje) return
  const r = interpretar(mensaje)
  if (r.tipo !== 'ackParametro') return
  const i = pendientes.findIndex(p => p.nodo === r.nodo && p.parametro === r.parametro)
  if (i < 0) return
  const [p] = pendientes.splice(i, 1)
  clearTimeout(p.temporizador)
  p.resolver(r.valor)
}

async function abrir(dev) {
  dispositivo = dev
  reensamblador = crearReensamblador()
  dev.addEventListener('inputreport', alRecibir)
  await dev.open()
  await dev.sendReport(0, empaquetar(SYNC_BEGIN))
  // El equipo cierra la conexion si deja de recibir latidos.
  latido = setInterval(() => {
    dispositivo?.sendReport(0, empaquetar(HEARTBEAT)).catch(() => desconectar())
  }, LATIDO)
  avisar()
}

async function desconectar() {
  if (latido) { clearInterval(latido); latido = null }
  const dev = dispositivo
  dispositivo = null
  for (const p of pendientes.splice(0)) { clearTimeout(p.temporizador); p.rechazar(new Error('se corto la conexion')) }
  if (dev) {
    try { await dev.sendReport(0, empaquetar(SYNC_END)) } catch { /* ya se fue */ }
    dev.removeEventListener('inputreport', alRecibir)
    try { await dev.close() } catch { /* ya se fue */ }
  }
  avisar()
}

// El navegador avisa cuando desenchufan el equipo.
if (typeof navigator !== 'undefined' && navigator.hid) {
  navigator.hid.addEventListener('disconnect', e => {
    if (e.device === dispositivo) desconectar()
  })
}

export const ampli = {
  soportado: () => typeof navigator !== 'undefined' && 'hid' in navigator,
  conectado: () => !!dispositivo,
  alCambiarEstado(fn) { oyentes.push(fn) },

  async conectar() {
    if (!this.soportado()) throw new Error('Este navegador no soporta WebHID. Necesitas Chrome o Edge.')
    let dev
    try {
      ;[dev] = await navigator.hid.requestDevice({ filters: [{ vendorId: VENDOR, productId: PRODUCT }] })
    } catch (err) {
      throw new Error(`No pude pedir el dispositivo: ${err.message}`)
    }
    if (!dev) throw new Error('No elegiste ningún amplificador.')
    try {
      await abrir(dev)
    } catch (err) {
      // El caso mas probable con diferencia: el equipo acepta un solo cliente.
      const exclusivo = /exclusive|already open|in use/i.test(err.message)
      throw new Error(exclusivo
        ? 'El amplificador ya está en uso. Cierra Fender Tone LT Desktop y vuelve a intentar.'
        : `No pude abrir el amplificador: ${err.message}`)
    }
  },

  // WebHID recuerda los permisos por origen: si ya se autorizo antes, se
  // reconecta sin mostrarle el selector al usuario otra vez.
  async reconectarSiSePuede() {
    if (!this.soportado() || dispositivo) return !!dispositivo
    const previos = await navigator.hid.getDevices()
    const dev = previos.find(d => d.vendorId === VENDOR && d.productId === PRODUCT)
    if (!dev) return false
    try { await abrir(dev); return true } catch { return false }
  },

  desconectar,

  /* Escribe un parametro y espera la confirmacion del equipo.
     El amplificador ignora en silencio lo que no entiende, asi que sin ACK no
     hay ninguna garantia de que algo haya cambiado: esta funcion rechaza en vez
     de mentir. */
  async ponerParametro(nodo, parametro, valor) {
    if (!dispositivo) throw new Error('El amplificador no está conectado.')
    const promesa = new Promise((resolver, rechazar) => {
      const temporizador = setTimeout(() => {
        const i = pendientes.findIndex(p => p.resolver === resolver)
        if (i >= 0) pendientes.splice(i, 1)
        rechazar(new Error(`El amplificador no confirmó ${parametro}`))
      }, ESPERA_ACK)
      pendientes.push({ nodo, parametro, resolver, rechazar, temporizador })
    })
    await dispositivo.sendReport(0, empaquetar(mensajePonerParametro(nodo, parametro, valor)))
    return promesa
  },
}
```
